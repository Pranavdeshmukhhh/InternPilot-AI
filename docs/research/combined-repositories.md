Push timestamps describe repository activity, not working service health or security certification. Dependency review was static; upstream projects were not installed or penetration-tested. Their authenticated application flows could not be verified without accounts, platform permission and specific candidate approval. Restrictions in a repository's code are not evidence of permission to scrape a website.

## Delivered boundaries

- `backend/app/aggregation.py`: bounded 8 MiB / 2,000-record imports, explicit remote booleans, timezone-aware instants, reference labels, safe URL checks and conditional HTTP fetching.
- `POST /api/imports/opportunities?provider=jobspy|internscan`: account-isolated canonical deduplication; stronger official data survives weaker imports. Raw export files are not retained.
- `internscan` and `jobspy_feed` source types: robots-aware read-only polling with retry/backoff and cache validators. An authorized JobSpy publisher must provide its own permitted feed; InternPilot does not grant board access.
- Durable automatic preparation produces factual versioned PDFs and stops before browser upload. Specific upload consent binds the candidate snapshot, listing, document and URL. External final submission remains manual.
- Worker recovery, bookmarks, deadline reminders, saved-listing changes and notification outbox records persist in the existing database. Provider calls require individual message approval. Ambiguous outcomes never automatically retry.

Live InternScan evidence is in [aggregation-validation.json](aggregation-validation.json); MLH/Simplify evidence is in [source-validation.md](source-validation.md). The [original six-repository audit](../UPGRADE_PLAN.md) remains separate from these five additions.
